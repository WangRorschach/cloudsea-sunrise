# 云海 · 日出 预测台

面向徒步者的云海与日出概率预报网页：3D 地形、海拔、多模式物理诊断、日出光路几何、卫星观测叠加、现场观测与 Brier 检验，以及带公式的方法文档。

## 运行

纯静态前端，无需 API Key：

```bash
python3 -m http.server 8765
# 打开 http://127.0.0.1:8765/
```

测试（Node 18+）：`node test/run.mjs`

## 手机与分享（单文件）

```bash
node tools/build-single.mjs   # 生成 dist/cloudsea-sunrise.html（约 1.7 MB）
```

这个文件已经内嵌全部脚本、样式、地点包和方法文档，可以直接通过微信、AirDrop 或网盘发送，用手机浏览器（Safari / Chrome）打开即可使用。地图瓦片和气象数据仍然需要联网获取。微信内置预览可能不运行脚本，请选择「用浏览器打开」。如需分享网址，可将该文件托管到任意静态空间，例如 GitHub Pages。

手机手势：
- 单指拖动：平移
- 双指捏合：缩放
- 双指扭转：旋转
- 双指同时上下推：调整俯仰
- 点「⟲ 旋转」后，单指左右拖动旋转、上下拖动调整俯仰，松手后带惯性

## 功能
- MapLibre 3D 地形（Mapterhorn / Copernicus GLO-30，中国区约 20 m/像素）、等高线、海拔分层设色、卫星/地形底图
- 旋转：右上角「⟲ 旋转」后直接拖动（松手带惯性），或右键拖动 / Ctrl+拖动；手机双指可同时缩放、扭转和俯仰；↺↻ 45° 旋转；「◎ 环绕」自动绕观测点
- 搜索：内置 12 座预置山周边的 OSM 地点包（客栈、山峰、观景台、索道站等，武功山约 200 处，如「武发客栈」），并实时检索地图周边 40 km 的 OSM；重建地点包：`python3 tools/build-pois.py`
- 按小时绘制预测云海面（多模式云顶高度），日出方位光路采样与透过率
- Open-Meteo 气压层数据：ECMWF / GFS / ICON / CMA GRAPES / JMA，逆温、湿度、低云、风、降水诊断
- 地形遮挡 + 眼高差 + 折射的真实日出时刻与方位
- NASA GIBS 卫星云图叠加；观测记录（本地存储）与预测检验
- `docs.html`：完整方法文档与局限性说明

- **云海详细预报**：按天列出云海时段（类型、云顶、云底、峰值、各模式概率），给出主要限制因子；7×24 小时概率热力图、云层高度走势图、逐小时诊断表，以及周边观景点在云上还是云中的对比。
- **3D 云海面**：在预测云顶高度绘制 WebGL 体感云层，与地形做深度遮挡，高于云顶的山峰会露出。

## 注意
评分为未经本地观测校准的物理诊断指数，仅供参考；山区徒步请以官方预警与现场判断为准。
